# Libron

Unmodified WOFF2 fonts from Libron v0.30:
https://github.com/nicoverbruggen/libron/releases/tag/v0.30

Source archive: Libron_Web.zip. All four styles are bundled: regular,
italic, bold, and bold italic. See Libron-LICENSE.txt and
Libron-COPYRIGHT.txt for the SIL Open Font License and attribution.

The default book and reader serif stack is `Libron, Merriweather, serif`.
Browsers use Merriweather for glyphs absent from Libron, or if Libron fails
to load, then the system serif font when neither bundled font has a glyph.

The release's character maps cover Latin-script languages, including
Western/Central European languages, Turkish, and Vietnamese. They contain
no Cyrillic, Greek, Arabic, Hebrew, Indic, or CJK letters. Coverage was
checked against all four release TTFs with Fontconfig's fc-query.
