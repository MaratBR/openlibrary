# Editor book previews

The user requests matching slash/sidebar insertion tools and a widget showing another book’s information.

## Acceptance criteria
- Slash commands and Blocks and formatting offer the same tools: code, code block, blockquote, divider, and book preview. Existing toolbar formatting stays available.
- The preview is compact and noticeable: at most 440px wide, a 48 × 72px cover, two-line title/summary, up to three tags, a subtle themed tint, and one row of actions.
- Book preview accepts a positive book ID or a same-library book URL, and displays the existing cover, title, author, summary, and tags with a book link.
- Published cards are rendered in the initial server response without a client preview fetch. Saved editor widgets receive pre-rendered server fragments and mount without accessing the editor view before it exists.
- The widget can be changed, deleted, saved, reloaded, and rendered in published chapters using the existing widget markup.
- Invalid input does not insert a book reference. Missing/private books and request failures show a useful state; the editor offers retry; access checks remain those of the existing preview endpoint.
- Widget markup only retains the book ID; preview HTML is generated by the server and never trusted from saved chapter content.

The requested scope defines these requirements; no open questions.
