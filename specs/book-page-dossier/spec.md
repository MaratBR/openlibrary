# Book page dossier

The user requested an interesting, functional redesign of the Cyberworld ALICE
book page and approved improvising a cover-led literary dossier. The shared book
template carries this presentation to book detail routes.

## Acceptance criteria

- Present the actual title, author, cover, rating, metadata, summary, sources,
  reviews, and chapters without inventing content.
- Keep existing library status, reporting, censorship, permissions, and tab behavior.
- Offer a direct first-chapter link only when a first chapter exists, preserving
  administrator override routing. Existing reading-status actions remain available.
- Desktop uses a wide title masthead and sticky cover/actions rail; mobile places
  a compact cover beside actions above the details. No horizontal overflow.
- Support both existing themes, visible keyboard focus, and reduced motion.
